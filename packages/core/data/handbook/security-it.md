# Information Security and Acceptable Use

## Accounts and passwords

Use a password manager to create and store a unique password for each work account. Multi-factor authentication is required on every work account, and a hardware security key is required for admin access. Never share passwords, even with IT. IT will never ask for your password.

## Devices

Company laptops use full-disk encryption and automatic screen lock after 5 minutes. Install updates within 7 days of their release. Do not install software that has not been approved by IT. Personal phones may be used for email and chat only if the company's mobile management app is installed.

Report a lost or stolen device to the IT service desk within 1 hour of noticing, day or night. IT can lock and wipe it remotely.

## Phishing

Report anything suspicious using the "Report phishing" button in your email, without clicking on links or opening attachments. Reporting a mistake early is always better than hiding one. Nobody is blamed for clicking a link if they tell IT immediately.

## Data classification

We classify data in four levels: public, internal, confidential and restricted. Customer data, payroll data and employee personal data are restricted. Restricted data may only be stored in approved systems, never on personal devices, personal cloud storage or email attachments sent outside the company.

## Using AI tools

You may use the AI assistants on the company's approved list for work. Never paste confidential or restricted information, such as customer data, source code from private repositories, or employee records, into public AI tools or any tool that is not on the approved list. Review AI-generated content before you use it. You remain responsible for its accuracy. When AI helped to produce customer-facing material, say so where the customer would expect to know.

## Security incidents

If you think data has been exposed, tell the security team at once at security@northwind.example. The company has 72 hours to notify regulators of some breaches, so speed matters.

## Leaving

On your last day all your accounts are disabled. Return all company equipment within 5 working days.
